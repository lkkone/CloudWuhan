# 云上武汉 · Wuhan in the Clouds

Three.js + Vite 实现的现代风格 3D 体素城市。长江串起黄鹤楼、长江大桥、龟山电视塔、江汉关与现代天际线，包含滨江樱花、渡轮、桥面车流和云端岛屿。属于艺术化城市印象，地标位置、比例与结构经过编排，不是测绘地图。

## 立即观看

双击 `dist/cloud-wuhan.html`，用支持 WebGL 的现代浏览器打开。这个文件已经内联脚本和样式，无需服务器、CDN 或网络资源。

开发预览：

```bash
cd /Users/likaikai/work/gitlab/cloud-wuhan
npm install
npm run dev
```

打开终端输出的本地地址（通常为 http://127.0.0.1:5173）。推荐 Node.js 22.12+。

生产构建与预览：

```bash
npm run build
npm run preview
```

构建生成标准网站 `dist/index.html` 和可独立打开的 `dist/cloud-wuhan.html`。将 `dist` 部署到任意静态网站服务器也可使用；相对资源路径支持子目录部署。

## 操作

- 拖动旋转、滚轮缩放；触屏支持单指旋转与双指缩放。
- 选择地标平滑聚焦；复位回到全景。
- 晨光、日间、蓝调切换光线与江水色调。
- 自动环绕；截图导出当前三维场景 PNG（不含网页文字界面）。
- 右上角问号查看说明；尊重系统减少动画偏好。
